# Student Skill Assessment System

## Overview

Student Skill Assessment System is a Python-based application designed to assess and analyze the skills of college students.

The system collects student details and skill scores, calculates the overall percentage, identifies the strongest and weakest skills, and determines the student's overall performance level.

## Problem Statement

Students develop different skills such as programming, communication, problem solving, and technical knowledge. However, evaluating these skills manually can be time-consuming and may not provide a structured view of a student's strengths and areas for improvement.

The Student Skill Assessment System provides a simple Python-based solution for collecting skill scores and generating an assessment result.

## Objectives

- Collect student information.
- Assess multiple student skills.
- Calculate total marks and percentage.
- Identify the strongest skill.
- Identify the skill requiring improvement.
- Determine the overall performance level.
- Generate a clear assessment report.

## Features

- Student information input
- Student category selection
- Skill-wise assessment
- Automatic score calculation
- Percentage calculation
- Strongest skill identification
- Skill requiring improvement identification
- Performance classification
- Terminal-based execution

## Skills Assessed

The system currently evaluates:

1. Programming Skill
2. Communication Skill
3. Problem Solving Skill
4. Technical/Subject Skill

Each skill is evaluated out of 10 marks.

## Technologies Used

- Python 3
- Python dictionaries
- Conditional statements
- Functions and input/output
- Basic data processing
